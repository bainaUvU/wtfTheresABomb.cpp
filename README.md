# 我靠这咋有个炸弹.cpp

游戏玩法和操作指南请参见下下下下下方 OvO

------------

这是一个 呃 由 @白呐UvU 独立开发，由他的朋友们提供灵感并鞭策的**控制台游戏** \
你可以通过局域网联机（ + 内网穿透或者其他方式 ）的方式和你的朋友们开玩 

这个仓库里包含两个东西：serverMain和clientMain \
如果你想当主机，点开serverMain，输入端口号 然后把**IPv4 + 端口**发给你的朋友们 \
然后自己点开clientMain加入房间就可以了（ 其他玩家加入也如此 ）

------------

## 游戏规则
在服务端（ 主机 ）开始游戏后，玩家们轮流出牌（ 顺序随机，和玩家进入房间的顺序无关 ）\
玩家们统一拥有 5 点体力，初始会有 Shovel + Double + **随机**的min(2, n / 2 + 1)张牌（ n 为玩家数量，结果保留整数部分 ） \
玩家在每一回合可以抽牌，每次抽牌会获得随机 1 ~ 2 张牌

矿井里有无尽延伸的土块，玩家可以消耗 Shovel 翻开土块，之后每个后方的土块都会前移 
**土块是从 0 开始编号的，但是你能看到的只有土块 0 ~ 土块 7** 

但是，每个土块里都有可能含有炸弹，炸弹的数量默认会是 1 颗，然而你可以在确定某个土块里含有炸弹后消耗 Double 来翻倍里面的炸弹 \
**每一颗炸弹都会对玩家造成 1 点伤害**，因此一定要谨慎 \
当一个玩家的体力归零时，玩家会被判定为和土块爆了
不过你可以消耗 MedKit 对自己包扎，恢复 2 点体力 \
而 FryingPan 会给你提供 2 点伤害抗性（ 抵抗 2 点伤害，然而在指数增长的伤害面前属于是空气 ）

玩家可以通过使用 MetalDetector 来探测随机一个土块里的情况 \
金属探测仪只会返回土块 0 ~ 土块 3 中任意一个土块的状况
然而，金属探测仪**仍然有6.67%的概率返回错误的结果**

Magnifier 会给你提供一次偷窥别人的手牌的机会， 而 FishingHook 能让你偷走他人的手牌 \
放大镜和鱼钩无疑是绝佳拍档，然而一定要注意如果使用鱼钩时 对方**并没有你想要的手牌** \
那么你反而会收到 1 点伤害

你也会有小概率得到 Bomb，你可以直接用它往土里埋入一个炸弹 \
**然而在别人看来，你只是对着某个格子使用了 Double**

不断存活，炸死其他玩家，存活下来

## 食用方法
在 serverMain 服务端：
 - #start 指令用于开始游戏
 - #quit 指令用于退出服务端（ 退出后也会立刻关闭其他客户端 ）

在 clientMain 客户端：
 - 输入不以 “#” 开头的消息会判定为聊天
 - #quit 指令用于退出客户

以下指令必须基于游戏已经开始的情况：
 - #showInfo 展示自己的手牌以及信息（ 并不会给别人看
 - #draw 指令用于抽牌，抽牌结果公开
 - #flip 指令*用于翻开土块 0
 - #double _pos 指令*用于翻倍土块 _pos 里的炸弹（ 0 <= _pos <= 7 )
 - #detect 指令*用于使用金属探测仪
 - #medkit 指令*用于使用急救包
 - #fryingPan 指令*用于使用平底锅
 - #magnifier _playerName 指令*用于使用放大镜偷窥玩家 _playerName 的手牌（ 必须是一个存在的玩家
 - #fishingHook _playerName _card 指令*用于使用鱼钩勾走 _playerName 的一张手牌 _card \
（ _card 必须是有效的牌 ）
 - #bomb _pos 指令*用于往土块 _pos 里埋入一颗炸弹（ 0 <= _pos <= 7 )

注：标注有 “*” 的指令需要消耗一张对应的卡牌
